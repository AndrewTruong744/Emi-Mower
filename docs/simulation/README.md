# Simulation

The [MuJoCo simulator](../../simulation/mujoco/README.md) runs one skid steer
mower for each connected Jetson simulation container. It includes a browser
viewer and a simple grass world.

For the current ROS simulation launch, see
[`nvidia_jetson/README.md`](../../nvidia_jetson/README.md). Cross-layer motion
assumptions should remain aligned with [CAN motion](../interfaces/can-motion.md).
